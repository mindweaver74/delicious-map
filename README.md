# 🍖🗺️ 회식 깨동여지도

> 직장인들이 다녀온 회식 맛집을, 옛 지도(대동여지도) 감성으로 한눈에

**▶ 바로 보기: https://mindweaver74.github.io/gaedong-map/**

<br>

## ✨ 소개

회식 깨동여지도는 흩어져 있던 회식 맛집 추천을 하나의 손그림풍 지도 위에 모아 보여주는 웹앱입니다.
권역(여의도·마포·강남·도심·용산 등)을 짚으면 그 동네 맛집만 필터링되고, 카드를 누르면 인원수·가격대·룸 유무·예약 방법 같은 상세정보가 펼쳐집니다.

- 설치 없이 링크만 열면 바로 사용
- 이름·메뉴로 검색, 인원수·룸 유무로 필터링
- 완전 오프라인 동작 (외부 폰트·API 의존 없음)

## 🛠️ 기술 스택

- 순수 HTML / CSS / JavaScript 단일 파일 (프레임워크·빌드 과정 없음)
- 데이터는 파일 내 JS 배열에 내장 (별도 백엔드 없음)

## 📦 이 저장소

```
index.html      회식 깨동여지도 전체 (지도 + 목록 + 상세정보 로직 포함 단일 파일)
```

## 📋 데이터 출처 및 한계

- 사내 동료들이 함께 정리한 회식 맛집 추천 목록을 바탕으로 제작되었습니다.
- 정확한 좌표 데이터가 없어 식당 위치는 **권역 단위**로만 표시됩니다(실제 지번과는 다를 수 있음).
- 인원수·가격대·예약 방법 등은 원본 자료 작성 시점 기준이며, 실제와 다를 수 있으니 **방문 전 전화로 확인**하는 것을 권장합니다.
- 일부 항목은 원본 확인이 어려워 "확인 필요"로 표시되어 있습니다.

## 🚧 다음 계획

지금은 고정된 데이터를 보여주는 정적 버전입니다. 이후에는 누구나 직접 맛집을 등록·추천할 수 있는 형태(가칭 "맛있을지도")로 확장할 계획입니다.
